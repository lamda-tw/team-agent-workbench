# 临时侧边提问

在 Codex 主会话或子会话中选中文字，通过浮层的“侧边提问”打开临时侧聊。原文会预填到可编辑输入框，等待用户发送。长期保留的子会话从左侧会话菜单的“创建子会话”创建；选中文字的浮层不提供创建子会话入口。

侧聊出现在已有右侧栏，与子会话、提问、AI 推荐并列。可以同时打开多个侧聊，分别切换、发送、停止和处理授权。收起侧栏保留输入与对话；关闭单个侧聊会先提示清除，不影响父会话或其他侧聊。

## 上下文与运行

- 当前仅支持 Codex。父会话正在生成时也可创建，不等待整轮结束，不执行压缩。
- 复用父会话已经连接的 App Server，调用一次 `thread/fork`，设置 `ephemeral: true`、`excludeTurns: true`；不创建新 CLI 进程，不复制项目文件，不要求历史文件路径。
- 原生分支继承服务端接受分叉请求时已有的上下文。请求发出前固定本轮已显示回复的末尾，作为补充参考；不会在分叉完成后读取父会话的新回复。服务端接收与用户点击之间仍有通信延迟。
- 通过开发者指令与 `thread/inject_items` 设置侧聊边界：历史只供参考，不接着执行父会话任务；默认做解释和阅读，修改需要用户在侧聊中明确要求。实际权限仍由原 Codex 配置约束，指令边界不等同于文件系统隔离。
- 消息、授权、停止按原生 thread ID 分发；侧聊关闭只中断并释放自身分支，不关闭共用连接。

## 生命周期

侧聊及其输入只保存在工作台内存中，不进入持久会话树、项目日志、阶段摘要或团队同步。退出应用后不恢复。原连接关闭或断开时，侧聊标记失效，已有文字暂留供查看或复制；继续提问需重新创建，不能悄悄用新上下文替换原分支。

切换账号清理临时侧聊。快照和每次操作校验父会话归属，个人项目与团队项目分别路由。删除父会话时清理对应临时侧聊。现有长期子会话仍走原来的保存、升级和多级管理流程。

创建结果不明时不自动重试，避免在较晚的上下文位置再建一个分支。已创建但边界注入失败的分支会释放，并向用户报告失败。

## 验证

`tests/side-chat.test.ts` 使用协议替身覆盖生成中分叉、消息与授权隔离、连接生命周期、失败清理、账号隔离和不落盘行为。

`node scripts/side-chat-ui-smoke.mjs` 使用独立数据目录和隐藏的 Electron 测试窗口，覆盖左侧仅创建子会话、选中文字仅打开侧聊或引用、原文预填、草稿保留、多侧聊切换、最终输出折叠、关闭及失效状态，不连接真实模型。
