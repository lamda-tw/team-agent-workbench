# 1.0.0 个人工作台验收记录

日期：2026-10-19。分支：`main`（从 `codex/personal-workspace-v0.7.9` 合入）。对应需求：[完整讨论与验收清单](personal-workspace-requirements-2026-10-19.md)。

本次在 Windows 11、临时数据目录、本地文件系统权限桩和 CLI 协议桩上验证。没有连接正式共享服务器，没有调用真实模型，没有生成安装包。版本号统一为 `1.0.0`，两个原启动脚本继续使用。

## 已实现并验证

| 范围 | 验证内容 |
| --- | --- |
| 个人入口 | 空白首次启动、登录失败后跳过、个人分组、独立目录、新建会话 |
| 本机工作 | 对话、独立整理、保存个人成果、成果再次引用、会话记录不显示上传控件 |
| 身份 | 重启保留；登录、断线、切换团队账号仍保留个人会话；已迁入的会话只在对应团队账号出现 |
| 密码 | 管理端创建无需输入密码、默认 123456、首次设置并确认、错误原密码拦截、短密码修改、新密码可登录和旧密码被拒绝 |
| 迁移 | 普通成员单会话和整组迁移；未登录、无目标权限、忙碌或另一中转身份时拒绝；迁移后继续对话 |
| 关联数据 | 工作目录、历史、草稿、输入草稿、保存成果和固定引用保留；Codex 原始记录复制到目标索引；摘要及最近日志保留 |
| 一致性 | 后台摘要在迁移期间暂停；磁盘失败保留恢复日志并拒绝继续编辑；重启恢复无重复记录；共享引用保留个人副本及目标发布回执 |
| 网络边界 | 直连不依赖团队登录；中央转发核对原账号；缓存运行器、成果整理助手和后台摘要继承同一身份；不自动换路线或重发 |

- `npm run typecheck`：通过。

- `npm run test:personal-ui`：15 个端到端场景通过，使用 CLI 协议桩。包括新增的会话记录界面检查。
- `node scripts/admin-management-smoke.mjs`：16 个管理员界面场景通过，包含默认密码、分组、角色、姓名和工号、重启保留。
- TypeScript 整体回归：684 项全部通过，日志 `.test-data/personal-final-suite.log`。其后新增的父子会话迁移用例随个人专项 8 项一起通过，日志 `.test-data/personal-final-core.log`。

- 界面截图保存在 `artifacts/personal-workspace/`，已检查个人会话及迁移确认窗口。

## 本版边界

1. 已通过 Git 合并主分支 `d1a994b` 的三项界面修复：项目目录入口、合并刷新按钮、取消文件上传的跳转与提示。个人工作台功能及版本号 `1.0.0` 同时保留。
2. 改密后保留现有连接，不自动重连；界面只提示密码已修改，不声称已自动验证新密码。自动复验属于需求记录中的待确认建议，本版没有扩大实现范围。测试通过另建连接验证了本地桩的新旧密码行为。
3. 真正 Linux 上的首次设密、PAM 密码策略、旧密码失效、ACL 及升级后的 worker 仍需目标环境验收；本轮未部署。
4. 离线授权细化、导出、跨项目独立发布等未确认扩展不在本版增加。

使用入口见[使用手册](user-guide.md#personal-workspace)，服务器升级步骤见[部署指导](deployment-guide.md)。
