# 管理端后台转发

使用根目录的 `start-admin-dev.cmd` 打开管理端，不需要 Windows 本机管理员权限。根目录保留两个启动入口：`start-user-dev.cmd` 打开用户端，`start-admin-dev.cmd` 打开管理端。

## 使用方式

1. 在管理端保存并启用网络出口。使用共享服务器中转时，按原流程登录服务器，等反向隧道显示已连接。
2. 点击窗口关闭按钮。窗口会转入系统托盘，出口和本次登录的反向隧道继续运行，保留原接入码、证书和端口，无需重复输入 SSH 密码。
3. 双击托盘图标，或再次运行 `start-admin-dev.cmd`，可重新打开同一个管理端，不会再启动第二个出口。
4. 真正停止时，右键托盘图标选择“退出并停止转发”。也可以在管理端停用出口；停用后关闭窗口会正常退出。

## 运行条件

“关闭管理端”指关闭窗口、保留托盘后台进程。后台驻留只在当前 Windows 登录期间运行；注销、关机或进程被结束时会停止。下次登录后重新打开管理端，反向隧道需重新登录服务器。SSH 密码仅保留在本次运行的内存中，不新增保存到磁盘。

电脑和原接入地址需要持续联网。如果出口依赖本机第三方 HTTP/SOCKS5 代理，该代理也要持续运行；管理端不会替你启动第三方代理。防火墙及网络配置仍按[网络出口说明](network-egress.md)处理。

系统托盘不可用时，界面会说明关闭窗口将停止转发，程序不会隐藏到无法重新打开的状态。首次更新驻留功能后，重启一次旧管理端即可加载新代码。

## 验证

后台测试覆盖关闭窗口驻留、明确退出、托盘不可用时的回退。构建后可执行：

```powershell
node --import tsx scripts/admin-background-smoke.ts
```

该验证使用独立数据目录和随机本地端口，检查窗口关闭后仍可认证连接、再次启动能恢复窗口、明确退出会停止出口；不读取或生成截图，不修改实际管理端的配置、接入码和端口。
