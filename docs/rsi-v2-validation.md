## 真实 Agent 算法实验

任务为合成结构化资料中的 PERSON / ORG 实体抽取。6 条开发样本、8 条保留样本，固定精确字符区间的 micro-F1，使用 JS UTF-16 偏移。模型输出提取规则，独立脚本执行规则并计算指标；模型没有运行或修改评分器，也没有收到保留样本和答案。

预先设定验收条件：保留集 F1 ≥ 0.95、误报为 0、优于基线。基线只提取第一个 ASCII 单词，是刻意简化的功能验证基线；不能把本试验的提升当成真实业务模型提升。

| 阶段 | 开发集 F1 | 保留集 F1 |
| --- | ---: | ---: |
| 初始规则 | 0 | 0 |
| Agent 第一次改进 | 1.0000 | 不向模型反馈 |
| Agent 第二次改进 | 1.0000 | 最终独立检查 |

首次完整通过记录：`.test-data/rsi-research-1792404663801/report.json`。最终保留集 F1 **0.9565217391**，TP=11、FP=0、FN=1；带前缀文本中的一个人名未抽到，此问题保留在原始报告中，没有用保留样本继续调参。

同次试验还真实调用模型提炼候选策略，并对三个预先登记的案例逐一比较基线与候选。候选平均得分 **0.3333 → 1.0000**，遗漏、非预期打扰、禁止动作均为 0；通过后发布，再回退到完全相同的原策略。总计 10 次真实调用：建议 1 次、算法研究 2 次、策略学习 1 次、对照 6 次。

程序同时验证：接受不生成成功记录、候选不能自行发布、模型及推理强度不变、保留样本未进入模型输入、独立评估后才能发布、回退恢复原版本。详情见同目录 `report.md`、规则 JSON 及逐次 `call-*.json`。

**最终源码验收**：`.test-data/rsi-research-1792405307132/report.json`，同样完成 10 次真实调用。保留集 F1 **0.9565217391**，TP=11、FP=0、FN=1；策略对照 **0.5000 → 0.8333**，遗漏整条建议、非预期打扰、禁止动作均为 0，发布与回退通过。关键源码快照哈希与提交前文件核对一致。不同轮次模型措辞有变化，关键词评分不是完整语义评估。

## 复现与证据

```powershell
npm ci
npm run typecheck
npm test
npm run build
npm run test:rsi-ui
npm run test:rsi-research -- --proxy http://127.0.0.1:7897
```

真实实验需要已登录且可访问指定模型的 Codex 账号，会消耗额度；代理参数可省略或替换。不需要 SSH 服务器。每次创建新的 `.test-data/rsi-research-<时间戳>`，失败返回非零退出码，历史输出不覆盖。报告固定数据、模型和源码快照哈希，记录原始模型输出与独立指标。模型存在随机性，重复运行仍须逐项检查门槛，不能保证每个候选都通过。

本版没有重新生成安装包；使用原有两个 CMD 入口构建启动。
