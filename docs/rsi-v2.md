# AI推荐：RSI 后台影子运行

[使用手册](user-guide.md) · [框架原文](../RSI框架.md)

## 开启与关闭

1. 使用原有 `start-user-dev.cmd` 启动，在“我的工作组”选择项目。
2. 点击项目可展开 **AI推荐** 滑动开关，再次点击可收起；其他项目未选中时不显示。收起不改变开关状态。切换开关立即保存，无需进入设置或再次确认。
3. 在本项目创建或打开工作会话，选择模型或沿用 CLI 已确认的默认模型。完成对话或项目资料更新后，助手异步分析。
4. 再次点击开关即可关闭；等待中的分析会撤销，正在进行的后台调用会取消，正常会话继续。

开关默认关闭，按当前账号和项目分别保存在本机；开启一个项目不会开启其他项目，也不会改变其他成员的设置。旧版本已保存的启停设置继续沿用。旧的“免打扰”显示为关闭，重新开启后恢复分析。

项目助手没有独立导航页、建议弹窗或会话提示。分析结果只写入本地记录，不自动加入输入框、改变会话上下文、执行命令、修改成果或上传共享空间。不会因为后台产生了建议，就记录用户已经查看或采纳。

分析沿用本项目最近创建且未关闭的工作会话模型。每项任务固定提供方、模型、推理强度和网络路线，使用独立的只读文本调用；开启后消耗个人模型账号额度。没有可用会话或尚未确定实际模型时，不调用模型。

## 后台记录与限制

- 采集当前账号可访问项目的开放工作会话、用户要求、工具记录、正式项目说明、已有成果与团队内容变化；不采集轨迹上传目录。
- 用户陈述、工具观察和模型推断保留来源、操作者、时间、版本、内容哈希及关联会话。模型自述成功不等于独立验证成功。
- 默认每日每项目最多 24 次后台调用，失败调用也计数。一次策略对照每案例调用两次，不自动无限重试。
- 默认参考上下文 12,000 字符，最多 40 条证据；固定协议和策略提示另有上限。这里按字符计算，不冒称模型 token 数。
- 自动分析有 10 分钟冷却，最多生成两条影子建议，并去重。单账号同一时刻只跑一个助手任务；工作会话忙碌时等待其完成。
- 证据、运行状态、影子建议和策略保存在本机账号数据目录的 `rsi-v2.json`，采用原子写入。没有新增服务器部署要求。
- 删除会话时清除相关证据、建议、冻结案例和派生策略。重启后把未完成任务标记为中断，不自动重发。

## 策略能力与影子运行边界

保留后台的证据收集、反馈账本、候选提炼、冻结案例对照、显式发布及回退接口，供开发调试使用。本版界面只提供项目开关，不提供建议采纳、策略发布或评审页面。

影子模式没有用户可见建议，不能凭空产生查看、采纳、拒绝或效果反馈。因此后台运行本身不代表完成学习闭环；候选提炼仍需要明确反馈或实际结果依据，不把用户无操作当成拒绝，也不自动发布策略。

独立对照先登记至少三个不同案例，包含一个不应建议的案例，再提炼候选。学习不获得保留案例的证据和预期答案；基线与候选使用相同模型和冻结输入。当前判分按预先指定的关键词、遗漏、打扰、禁止动作及输出开销检查，质量需提高至少 0.05，且不能增加遗漏、违规或打扰。这不等于开放任务的完整语义评价。

候选只调整提示词及检索顺序，不改变底层模型、权限或预算；冷却时间与建议数量继承基线。跨项目只允许同账号复制已验证策略为候选，目标项目仍须重新验证；不复制原项目会话。长期偏好仅来自明确填写。

## 基础测试

```powershell
npm run typecheck
npm run test:rsi
npm run build:check
```

仓库保留核心与工作台适配的基础用例，覆盖身份与项目隔离、触发调度、后台开关、预算、上下文边界、证据来源、策略验证与回退，以及影子结果不改变正常会话。端到端实验脚本、运行报告和验收材料仅在本地保留，不进入 Git 跟踪，也不作为日常测试依赖。
